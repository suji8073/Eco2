## 👀  웹 서비스 소개

<img width="1262" height="413" alt="image" src="https://github.com/user-attachments/assets/b5588bdc-6f20-416c-8c4c-f75bcd364168" /><br/><br/>

배달·간편식 증가로 생활 폐기물, 특히 플라스틱 배출량이 급증하고 있음에도 시민들은 품목별 분리배출 기준을 정확히 알기 어려워 오분리 문제가 지속되고 있습니다. 기존 분리배출 앱들 역시 사용자가 직접 품목을 검색하거나 메뉴를 일일이 탐색해야 하는 번거로움으로 인해 실제 사용률이 낮은 상황입니다.
 
이 문제를 해결하기 위해 저희는 **카메라 촬영만으로 AI가 폐기물을 자동 인식하고 즉시 분리방법을 안내해 사용자의 피로도를 최소화**고, **AI 캐릭터 ‘이코(Eco)’를 중심으로 한 게이미피케이션 요소 및 유상 수거함 위치 연계 등 현실 보상 기능**을 제공하는 앱을 개발하고자 하였습니다. 이를 통해 저희는 분리배출을 ‘해야 하는 일’에서 ‘하고 싶은 경험’으로 전환하는 **국내 최초의 AI 코칭 + 게임화 결합 분리수거 서비스**를 제작하고자 합니다.

## ✨ 주요 기능

### 📸 AI 쓰레기 스캐너

사용자가 폐기물을 촬영하면 AI가 **재질, 형태, 혼합 여부** 등을 분석해 바로 분리배출 방법을 안내합니다.

### 💬 채팅

이코 캐릭터와 함께 분리배출 관련 질문에 대한 답변을 받을 수 있습니다.

### 🎮 게이미피케이션

분리배출 정확도에 따라 **AI 캐릭터 수집 보상**을 받으며 재미있게 환경을 보호할 수 있습니다.

### 💡 맞춤형 코칭 피드백

_"이물질이 남았으니 미지근한 물에 헹궈보세요."_ 와 같이 분리배출에 대한 **실시간 피드백**을 제공합니다.

### 🗺️ 위치 기반 서비스

사용자 위치 기반 **재활용품 회수 보상 거점**과 **친환경 매장**을 안내합니다.

## 🚀 실행 방법

### 📋 사전 요구사항

- **Node.js** 18.0.0 이상
- **Yarn** 4.9.2 이상

### 🔧 설치 및 실행

```bash
# 1️⃣ 저장소 클론
git clone https://github.com/eco2-team/frontend.git
cd frontend

# 2️⃣ 의존성 설치
yarn install

# 3️⃣ 환경 변수 설정 (.env 파일 생성)
VITE_KAKAO_MAP_API_KEY=your_kakao_javascript_key
VITE_API_BASE_URL=https://your-api-server   # 데모 모드에서는 불필요
VITE_DEMO_MODE=true                          # 백엔드 없이 mock 응답으로 실행

# 4️⃣ 개발 서버 실행
yarn dev

# 5️⃣ 빌드
yarn build

# 6️⃣ 배포
yarn deploy
```

### 📜 주요 스크립트

| 명령어         | 설명               |
| -------------- | ------------------ |
| `yarn dev`     | 개발 서버 실행     |
| `yarn build`   | 프로덕션 빌드      |
| `yarn lint`    | ESLint 실행        |
| `yarn preview` | 빌드 결과 미리보기 |
| `yarn deploy`  | GitHub Pages 배포  |

### 🧪 데모 모드

백엔드 없이 화면을 확인할 수 있도록 `VITE_DEMO_MODE=true`일 때 모든 API 요청을 [`src/api/mock/demoAdapter.ts`](src/api/mock/demoAdapter.ts)의 mock 응답으로 처리합니다.

- **로그인**: 소셜 로그인 버튼 클릭 시 바로 홈으로 이동
- **AI 스캐너**: 촬영 시 페트병 → 종이 → 유리병 → 캔 순서로 예시 결과와 캐릭터 보상 제공
- **캐릭터 / 닉네임**: 브라우저 localStorage에 저장
- **지도**: 현재 위치 주변의 예시 거점 표시 (카카오 JavaScript 키에 배포 도메인 등록 필요)
- **채팅**: 예시 답변 제공

Vercel 배포 시 프로젝트 환경 변수에 `VITE_DEMO_MODE=true`, `VITE_KAKAO_MAP_API_KEY`를 설정합니다.
